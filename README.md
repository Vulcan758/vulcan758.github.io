# vulcan758.github.io

Personal site of Al Mahir Ahmed — plain HTML/CSS/JS, no build step.

- `index.html` — content
- `style.css` — styles
- `rrt.js` — the live RRT animation in the hero

Preview locally: `python3 -m http.server 8000` then open http://localhost:8000.
Deploy: push to `main`; GitHub Pages serves the repo root.
